# Weather Information System

## Project Description
This project is a Weather Information website developed using Python Flask, HTML, and CSS.

## Technologies Used
- Python and Flask
- HTML and CSS
- Docker
- Git and GitHub
- Jenkins

## Features
- Weather dashboard interface
- City search interface
- Flask web application
- Docker containerization
- Jenkins CI/CD pipeline
- Health-check endpoint

## How to Run
1. Install Python and Docker Desktop.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://localhost:5000` in your browser.

## DevOps Workflow
GitHub stores the project code, Jenkins automates the pipeline, and Docker builds and runs the application container.

**Note:** The current dashboard uses demo weather values. Live weather data requires a weather API.
